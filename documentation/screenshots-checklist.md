# ThemeForest Preview Screen Checklists

This checklist organizes high-resolution mock layout snapshots required for product presentation and promotion on the ThemeForest marketplace.

---

## 📸 Recommended Snapshots Checklist
- [ ] **01-homepage.png:** Full-page scroll of the primary editorial homepage layout (NOVARA default).
- [ ] **02-shop-catalog.png:** Shop catalog grid highlighting sidebar price, color, and rating filters.
- [ ] **03-product-details.png:** Product details interface showcasing variants choice, selectors, reviews count, and gallery layout.
- [ ] **04-mobile-home.png:** Home layout rendered inside a viewport device shell (e.g. iPhone 15/16 Pro).
- [ ] **05-wishlist.png:** Saved items checklist with quick checkout triggers.
- [ ] **06-shopping-cart.png:** Sidebar cart drawer slide-out with subtotal discount calculations.
- [ ] **07-checkout-payment.png:** Validation form fields, shipping options select, and mock gateway placeholder selectors.
- [ ] **08-blog-journal.png:** Grid layout of editorial blog posts.
- [ ] **09-blog-details.png:** Article details view showing readable paragraphs, social sharing components, and tags.
- [ ] **10-account-settings.png:** Customer orders lists and address settings layouts.

---

## 🎨 Asset Guidelines
- **Resolution:** Minimum 1920x1080px for desktop screen previews, and 750x1334px for mobile devices.
- **Background Context:** Avoid browser headers/address bars in screenshots. Place mock layouts inside elegant clay mockup frames.
