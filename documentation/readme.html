NOVARA Template Documentation

Welcome to the official documentation for the **NOVARA Premium Next.js Ecommerce Template**. NOVARA is built on Next.js 16 (App Router), React 19, and Tailwind CSS v4, providing a clean, modular design layout optimized for performance and scalability.

2. Features

  • Next.js 16 App Router: Complete structural alignment using Server and Client components.
  • Advanced Catalog Filtering: Filter by Category, Price Range, Minimum Rating, and Availability.
  • Zustand State Management: Persistent Cart, Wishlist, and simulated Authentication state.
  • Clean Architecture: Reusable atomic components and modular mock structures.
  • Responsive layout grid: Tested from 320px up to 1920px widescreen monitors.

3. Requirements

Ensure the following software packages are installed on your workstation environment:

  • Node.js: v18.0.0 or higher (v20+ recommended).
  • Package Manager: npm, yarn, or pnpm.

4. Installation

Decompress the zip files, open the command line terminal, and run:

npm install

5. Development

Initiate the local development hot-reload server by running:

npm run dev

Navigate your browser page to http://localhost:3000 to view the project live.

6. Production Build

To compile the production distribution bundle, run:

npm run build
npm run start

7. Deployment

The simplest way to host your template is on **Vercel**:

npx vercel

Follow the CLI prompts to deploy directly.

8. Project Structure

├── src/
│   ├── app/            # Next.js App Router (pages and layouts)
│   ├── components/     # UI widgets and structural parts
│   ├── data/           # Mock data models (products.ts, categories.ts, blog.ts)
│   ├── lib/            # Utilities and configurations
│   ├── store/          # Zustand stores (useCartStore, useWishlistStore)
│   └── types/          # TypeScript interfaces definitions

9. Logo, Colors, and Fonts

Changing Logo Text & Info:

Edit the configuration file inside src/lib/brand.ts to update the brand parameters:

export const brand = {
  name: "NOVARA",
  logoText: "NOVARA",
  contactEmail: "hello@novaradesign.com",
  ...
};

Changing Colors:

Modify color parameters inside the tailwind structure src/app/globals.css or the component definitions.

Changing Fonts:

Fonts are imported inside the root layout src/app/layout.tsx via Google Fonts. Change the stylesheet URL import values to use your preferred family.

10. Managing Catalog & Data

Products are centralized in src/data/products.ts. You can easily add or edit objects matching the Product typescript interface:

{
  id: "prod-1",
  name: "Your Custom Product Name",
  slug: "your-custom-product-name",
  price: 199,
  category: "Fashion",
  ...
}

11. Editing Navigation & Footer

  • Navigation: Modify navLinks arrays in src/components/layout/Navbar.tsx.
  • Footer: Edit details in src/components/layout/Footer.tsx.

12. Checkout & Backend Connect

The checkout routing files in src/app/checkout/page.tsx use **Zod** schema structures. You can connect standard endpoints (e.g. Stripe, PayPal, or MedusaJS) inside the onSubmit callback function.

13. Troubleshooting

If you encounter layout shifts or compilation issues, reset the project cache:

rm -rf .next
npm install
